# Byron Bursett portfolio notes

FrankenChess is a shared Godot game developed by the BYU-Idaho Winter 2026 game-development team. Team members contributed code, models, assembly UI, music, sound, and other assets. This note records a focused contribution summary without changing gameplay or the team's main README.

## Contributions supported by repository history
