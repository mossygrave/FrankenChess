# FrankenChess
Repository for the FrankenChess game. Project made for the Game Development class at BYU-I. Winter 2026

Frankenchess is a game unlike any other. If you love the game chess, then you might like this roguelike. Much like Frankenstein's monster, youll be putting together your own Frankenstein chess pieces to make new combinations of pieces unlike ever before. Imagine destroying the knight of the enemy team, getting a random piece from the knight, then upgrading your pawn to be able to attack like the knight but still move like the pawn.

This is what Frankenchess is all about. It requires creative thinking and foresight to be able to craft the ultimate army.
